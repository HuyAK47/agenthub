# AgentHub 1.0.0-rc.9

Bản pre-release này tổng hợp các thay đổi từ `v1.0.0-rc.8` đến HEAD (361 commit không phải merge).

## Tính năng

- Bổ sung engine Codex, cơ chế failover hai chiều và tự động merge sau khi review được chấp thuận.
- Thêm hệ thống phòng ban: brain theo phòng ban, phân bổ công bằng, giới hạn ngân sách và số worker.
- Thêm workflow review nâng cao: cấu hình thứ tự reviewer, reviewer dự phòng, retry khi bị từ chối và giới hạn vòng arbiter.
- Thêm guided project wizard, kiểm tra repository, context summarization, knowledge và review checklist theo project.
- Thêm project focus, worktree roots cấu hình được, archive/purge project và theo dõi tình trạng worktree.
- Thêm quản lý kế hoạch, deploy queue, trạng thái deploy và khả năng tiếp tục công việc sau khi daemon khởi động lại.
- Thêm chính sách thông báo, audit, chuẩn hóa thời gian quota reset và hỗ trợ nhiều tài khoản provider.
- Thêm lệnh quản lý daemon (`start`, `stop`, `status`) và tùy chọn quyền đầy đủ cho assistant.

## Sửa lỗi

- Cải thiện độ an toàn của shell/read shim, sandbox, launcher và các đường dẫn mount; ngăn các cách vượt policy.
- Sửa nhiều race condition trong scheduler, worker completion, review, auto-merge, restart recovery và shutdown.
- Sửa migration/database cho department, focus, external reference và dữ liệu project cũ.
- Cải thiện xử lý quota và thông báo: chống trùng, debounce, giữ tương thích dữ liệu cũ và định tuyến đúng phạm vi project.
- Sửa Telegram topics, external reference Unicode, callback lifecycle và bảo toàn thread/reply.
- Sửa installer để hỗ trợ runtime Node native, rollback an toàn và kiểm tra phiên bản công cụ.
- Sửa các vấn đề bảo mật liên quan đến secret trong chat, branding, project nhạy cảm và worker shims.

## UI

- Thêm dashboard phòng ban, project focus, project wizard, context progress và các màn hình cài đặt mới.
- Thêm phân trang/cursor cho task, kanban, runs, plans, sessions, activity, knowledge, savings và CI history; đồng thời virtualize log.
- Thêm giao diện review fallback, reviewer badge/history, timeline và kiểm soát thứ tự reviewer.
- Thêm branding tùy chỉnh, logo, dark/light theme tokens, guided tour, onboarding checklist và bản dịch Việt/Anh.
- Cải thiện responsive landing page, mobile layout, modal/overlay, notification policy, bảng project và các trạng thái shutdown.
- Thêm giao diện Telegram topics theo project/phòng ban và các màn hình quản lý cấu hình liên quan.

## Cài đặt

```sh
curl -fsSL https://raw.githubusercontent.com/ducanh19020217/agenthub/main/scripts/install.sh | sh -s -- --from-release 1.0.0-rc.9
```

Release macOS gồm `agenthub-1.0.0-rc.9-macos-arm64.tar.gz` cho Apple Silicon và `agenthub-1.0.0-rc.9-macos-x64.tar.gz` cho Intel. Hai archive đã kèm production `node_modules` (bao gồm native `node-pty` và `better-sqlite3`), nên không cần Node, git, nvm hoặc Xcode Command Line Tools khi cài từ release. Installer kiểm tra `SHA256SUMS`, tải Node.js 22 đúng kiến trúc, và cài LaunchAgent tại `~/Library/LaunchAgents/dev.agenthub.plist`.

Nếu Gatekeeper chặn `spawn-helper`, tải lại archive hoặc bỏ quarantine trên thư mục phiên bản bằng `xattr -dr com.apple.quarantine ~/.agenthub-app/1.0.0-rc.9`, rồi chạy `agenthub start`. Cài đặt lỗi sẽ rollback về bản trước; `--uninstall` giữ dữ liệu `~/.agenthub/`, còn `--uninstall --purge` yêu cầu xác nhận trước khi xoá dữ liệu.

CI release kiểm thử cả runner Intel (`macos-13`) và Apple Silicon (`macos-latest`) trước khi job `publish` gom archive và tạo lại `SHA256SUMS`.
