# AgentHub 1.0.0-rc.12

Bản pre-release sau `v1.0.0-rc.11`, tổng hợp các tính năng và cải tiến từ 11 nhánh merge trên nhánh `integration`.

## Tính năng

- **Tùy chọn truy cập Dashboard qua mạng LAN**: Thêm cờ `--allow-lan` và biến môi trường `AGENTHUB_ALLOW_LAN`, cho phép truy cập dashboard an toàn từ thiết bị trong mạng nội bộ.
- **Tự động đóng bản nháp merge fix cũ**: Hệ thống tự động phát hiện và đóng các bản nháp sửa lỗi merge (merge fix drafts) đã lỗi thời khi nhánh hoàn tất hoặc thay thế.
- **Hoàn thiện giao diện phân bổ phòng ban**: Bổ sung bộ điều khiển gán phòng ban đầy đủ trên trang Projects và Departments, đồng thời lưu trữ tính kế thừa brain theo phòng ban.
- **Cấu hình reviewer và model theo dạng danh sách chọn**: Thêm component `SelectOrCustomInput` và `SortableModelList`, thay thế ô nhập tự do bằng điều khiển có cấu trúc, kiểm tra cú pháp theo quy tắc engine và hỗ trợ xóa ghi đè bằng `null`.

## Sửa lỗi

- **Dọn dẹp thư mục tạm an toàn & bất đồng bộ**: Xử lý xóa tệp tạm thời theo phương thức bất đồng bộ để tránh bị hệ thống EDR ngăn chặn hoặc gây lỗi khoá tệp.
- **Bộ cài đặt**: Tránh treo trên `/dev/tty` khi chạy trong môi trường non-interactive (CI/automation); đồng bộ cờ `--from-release` trên landing page.
- **Thực thi an toàn lệnh CLI Claude**: Chuyển sang `execFileSync` thay vì shell để kiểm tra CLI Claude an toàn và tránh các rủi ro injection.
- **Bảo toàn cấu hình**: Giữ nguyên danh sách các profile không hoạt động (inactive profiles) khi cập nhật reviewer trong trang cài đặt.

## Giao diện và đa ngôn ngữ

- **Tinh gọn Dashboard**: Đơn giản hóa bố cục tổng quan Dashboard giúp theo dõi công việc nhanh và trực quan hơn.
- **Bổ sung các trạng thái lỗi và thử lại**: Thêm hiển thị lỗi cùng nút thử lại trên các trang Setup, Projects và Profiles.
- **Trợ năng và an toàn thao tác**: Yêu cầu xác nhận trước khi xóa worktree, thêm nhãn cho nút quay lại (back button) và bổ sung các thuộc tính `aria-label` cho icon button, knowledge notes.
- **Đa ngôn ngữ (i18n)**: Bổ sung các bản dịch tiếng Việt và tiếng Anh còn thiếu cho phân trang, trạng thái brain và các nhãn điều hướng; giữ phản hồi kiểm tra model độc lập với ngôn ngữ.

## Bảo mật

- **Cập nhật các gói phụ thuộc**: Sửa các lỗ hổng bảo mật đã cảnh báo trong `body-parser` và `fast-uri` qua `npm audit fix`.

## CI và Release Pipeline

- **Xuất bản release qua GitHub REST API**: Chuyển đổi cơ chế publish release trong workflow sang GitHub REST API để tăng tính ổn định, hỗ trợ upload asset an toàn và định nghĩa rõ tiêu chuẩn hoàn tất release.
- **Môi trường kiểm thử**: Cô lập các git repository tạm trong test suite và cho phép ghi file dịch vụ trong thư mục tạm của test.

## Cài đặt

```sh
curl -fsSL https://raw.githubusercontent.com/ducanh19020217/agenthub/main/scripts/install.sh -o /tmp/agenthub-install.sh
sh /tmp/agenthub-install.sh --from-release
```
