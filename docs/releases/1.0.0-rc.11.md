# AgentHub 1.0.0-rc.11

Bản pre-release sau `v1.0.0-rc.9`.

## Tính năng

- Bộ cài macOS: đóng gói archive macOS (arm64, x64) trong release, installer Darwin và smoke test; các job macOS vẫn non-blocking cho tới khi xác minh trên runner thật (DEC-010).
- Setup Antigravity: hỗ trợ cài agy bằng lệnh chính thức, dò binary ở nhiều vị trí và cho phép cấu hình `AGENTHUB_AGY_BIN`.

## Sửa lỗi

- Thêm mới tài khoản agy không còn lỗi `execvp failed`; nút kết nối lại luôn hiển thị trạng thái và lỗi cụ thể.
- Trình hướng dẫn dự án: tóm tắt ngữ cảnh lỗi không chặn việc tạo dự án, có nút thử lại và xử lý đúng trạng thái queued/running.
- CI: test độc lập với `bwrap`, `flock`, `lockf`, `nice` trên máy host.

## Giao diện và đa ngôn ngữ

- Bổ sung bản dịch vi/en còn thiếu, dịch lỗi API theo mã lỗi, test quét chuỗi hard-code.

## Cài đặt

```sh
curl -fsSL https://raw.githubusercontent.com/ducanh19020217/agenthub/main/scripts/install.sh -o /tmp/agenthub-install.sh
sh /tmp/agenthub-install.sh --from-release
```
