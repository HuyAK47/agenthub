06 — FAQ

Những câu hỏi
thường gặp.

AgentHub có gọi API Claude trực tiếp không?

Không. Bộ não dùng Claude Code đã cài trên máy; AgentHub điều phối qua tiến trình và MCP.

Tôi có cần nhiều tài khoản không?

Không bắt buộc. Nhiều profile giúp tận dụng quota song song.

Code có rời khỏi máy tôi không?

AgentHub chạy local. Quyền truy cập model và dữ liệu tuân theo CLI/provider bạn cấu hình.

AgentHub có miễn phí không?

Mã nguồn phát hành theo AGPL-3.0. Chi phí model phụ thuộc tài khoản và provider.
